# Convert Model to MaixCAM Format

This tool converts a trained YOLO segmentation model to MaixCAM format using TPU-MLIR.

## Prerequisites

- Docker must be installed and running
- Sufficient disk space for temporary files and Docker images

## Usage

```bash
# Basic usage
chalk convert_model --model-path path/to/model.onnx --train-data path/to/training/images/

# With custom test image
chalk convert_model --model-path model.onnx --train-data train_images/ --test-image test.png

# With custom output directory
chalk convert_model --model-path model.onnx --train-data train_images/ --output-dir converted_models/

# With fewer calibration samples (faster conversion)
chalk convert_model --model-path model.onnx --train-data train_images/ --calibration-samples 100
```

## Arguments

- `--model-path`: Path to the ONNX model file to convert (required)
- `--train-data`: Path to directory containing training images for calibration (required)  
- `--test-image`: Path to test image (optional, uses random training image if not provided)
- `--output-dir`: Output directory for converted model (optional, defaults to same directory as input model)
- `--model-name`: Name for the converted model (optional, default: "yolov11n-seg-chalk")
- `--calibration-samples`: Number of samples to use for INT8 calibration (optional, default: 200)

## Process

1. Creates temporary workspace
2. Copies required files (model, training images, test image)
3. Builds Docker image with TPU-MLIR tools
4. Runs conversion inside Docker container
5. Copies converted model files to output directory
6. Cleans up temporary files

## Output

The tool generates:
- `{model_name}_int8.cvimodel`: Quantized INT8 model for MaixCAM
- Additional files as generated by TPU-MLIR

## Notes

- The conversion process requires calibration using training images
- INT8 quantization is used for optimal performance on MaixCAM
- Docker container is automatically cleaned up after conversion
